# Image Classification Using Supervised Machine Learning

## Project Overview

This project performs handwritten digit classification using the MNIST dataset and supervised machine learning algorithms.

## Dataset

MNIST Handwritten Digit Dataset

- Training Images: 60,000
- Testing Images: 10,000
- Image Size: 28 × 28 pixels
- Classes: 0–9

## Machine Learning Models

- Logistic Regression
- Random Forest

## Results

The Random Forest model achieved the best performance.

- Accuracy: 97.04%
- Precision: 97.04%
- Recall: 97.04%
- F1 Score: 97.04%

## Technologies Used

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Conclusion

The project successfully classified handwritten digits using supervised machine learning. Random Forest achieved the best performance with an accuracy of 97.04%.
